Our Website:
We always take the first definition and all information relating to that first definition since words can have multiple varying definitions but we reasoned that if the word is defined within the database it will be guaranteed to have at least one definition, so we always take the first definition.
There are instances where there can be multiple ways to obtain data for the word and we chose to use the arrays for the most part in determining what data to display to the user for example: in some data sets there is a phonetic key and value and a phonetic array with dictionaries inside with keys and values relating to phonetic spelling and audio mp3 files.
We chose to always take our phonetic spelling to be displayed to the user from the phonetic array with dictionaries inside since thre are instances when the phonetic key and value aren't always present in the data set. 
Similarly with synonyms and anytonyms we chose to always display the synonyms and antonyms found in the index of the meaning array not the synonyms and antonyms found in the index of the definition array.
